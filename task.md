## 1. ЦЕЛЬ И БИЗНЕС-ТРЕБОВАНИЯ

1. **Вкладка Делюги -> Ежедневки и рутина: отдельный блок авто-действий (Бицуха / Баланда / Дрожжи)**:
   - Добавить отдельный визуально выделенный блок с тремя позициями:
     - **Качать бицуху**
     - **Плевать в баланду**
     - **Кидать дрожжи**
   - У каждой из трех позиций должен быть **свой независимый ползунок включения (`АВТО`)** (и при наличии данных - компактный статус/счетчик выполнения за день, например `выполнено / лимит`).
   - Если ползунок включен на `АВТО`:
     - бот автоматически собирает пул доступных целей из всех имеющихся источников (друзья, участники бригад, списки/радар/кандидаты, поиск игроков и т.д.) и выполняет включенное действие всем подряд **до полного суточного лимита**;
     - после сброса суточного лимита (секунда в секунду по времени сервера `Europe/Moscow` / игровому таймеру сброса) бот **автоматически запускается снова** и отрабатывает действие до лимита - и так каждый цикл, пока пользователь сам не выключит ползунок `АВТО`.
     - при включении ползунка из UI бот немедленно запускает проверку и докручивает действие до лимита, если лимит на сегодня еще не выбран.
2. **Вкладка Боссы -> Исправление нулевых значений прогресса талантов в блоке активного боя**:
   - Сейчас миниблок `Таланты` успешно встроен внутрь карточки активного боя (`Воркута`, `Личный урон: 67`), но отображает нули: `0 / 0`, пустой прогрессбар, `Очки: 0`, `Новые: 0`[cite: 53].
   - При этом в игре и на главной странице панели отображается актуальная статистика: `67 / 90` (`74%`), `Очков: 12`, `Новые (свободно): 0`[cite: 54, 55].
   - Нужно устранить причину рассинхрона/обнуления (непереданные данные, перезапись DOM при рендере карточки боя, неверные ID элементов или отсутствие синхронизации с общим состоянием талантов) и гарантировать, что в блоке активного боя всегда показываются актуальные `current / target` (например `67 / 90`), заполненный прогрессбар, реальные `Очки` и `Новые`, с живым обновлением после каждого удара.
   - При отсутствии активного боя на месте карточки боя должен отображаться idle-блок талантов со сброшенным прогрессом `0 / target` и актуальными `Очки` / `Новые`.
3. **Обязательный деплой на VPS и сохранность соседних сервисов**:
   - Обновить cache-busting `?v=...` в `web/static/index.html`, выкатить все изменения (включая миграцию новых полей настроек в SQLite) на VPS (`178.17.60.16`, `/opt/prisonbot`), перезапустить `prisonbot.service` и проверить живую работу.

### 3.2. Вкладка Боссы - починка отображения актуального прогресса талантов
- Файлы: `web/static/app.js`, `web/static/index.html`, `web/routes.py`[cite: 56, 57].
- **Диагностика**:
  - Проследить, откуда главная страница берет данные для блока `Таланты арестанта` (`Очков: 12 (свободно: 0) | До следующего: 74%`)[cite: 55] и почему внутри `#boss-active-card` виджет `#boss-talents-widget` показывает `0 / 0`, `Очки: 0`, `Новые: 0`[cite: 53].
  - Проверить 4 вероятные точки сбоя:
    1. Перезапись содержимого `#boss-active-card` при обновлении боя (`renderBossActiveFight`) сбрасывает DOM-элементы `#boss-talents-widget` обратно в `0 / 0`, не вызывая повторно `renderBossTalentsWidget(lastTalentsState)`.
    2. Несовпадение имен полей между ответом `/api/v1/talents` (или `/api/v1/profile/live`) и тем, что читает `renderBossTalentsWidget` (например `damage / nextPointDamage` vs `current / target`, `totalPoints` vs `points`, `freePoints` vs `newPoints`).
    3. При открытии сразу вкладки `Боссы` (без предварительного захода на главную) запрос данных талантов вообще не дергается, и кэш талантов остается пустым.
    4. Дублирование одинаковых `id` между `#boss-talents-widget` (внутри активного боя) и `#boss-talents-idle-card` (вне боя).
- **Исправление**:
  - Ввести единый источник правды `latestTalentsState` в `web/static/app.js` (заполняется при загрузке главной, при загрузке вкладки Боссы, при SSE-обновлениях и после каждой атаки босса).
  - Убедиться, что при активном бое `#boss-talents-widget` внутри `#boss-active-card` всегда показывает реальные `current / target` (например `67 / 90`), ширину прогрессбара `Math.round(current / target * 100)%`, `Очки: 12` и `Новые: 0`[cite: 54, 55].
  - При неактивном бое `#boss-talents-idle-card` показывает `0 / target` (полоса `0%`) и актуальные `Очки` / `Новые`.
  - Проверить визуально через MCP DevTools на живом интерфейсе, что значения в карточке боя 1-в-1 совпадают с главной страницей и игрой.
